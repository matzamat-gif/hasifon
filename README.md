# חֲשִׂיפוֹן

מחשבון כשל הדדיות (Schwarzschild effect) לחשיפות לילה בצילום פילם.
עמוד אחד, עובד אופליין, אפס בקשות רשת.

**לשימוש:** https://matzamat-gif.github.io/hasifon/
באייפון: לפתוח ב-Safari → שיתוף → הוספה למסך הבית.

## מה יש בו
- 25 סרטים, 35 מ"מ ו-120
- תיקון ND שמחושב לפני ההדדיות (אובדן אור חל על הזמן המדוד, לא על התוצאה)
- תיקון פיתוח והמרה לעצירות צמצם
- פילטרי CC רשמיים לשקופיות
- יומן צילום שממנו נגזר תיקון אישי לכל סרט
- טיימר שדה עם רטט וצליל

## מקורות הנתונים
כל מקדם נושא את מקורו, ומוצג בתחתית המסך.

- **Ilford** — HARMAN, Film Reciprocity Failure Compensation, Dec 2023. `Tc = Tm^P`
- **Kodak** — F-4017 (Tri-X), F-4043 (T-Max 400), F-4016 (T-Max 100), E-31, E-4046
- **Fujifilm** — דפי נתונים של Acros II, Provia 100F, Velvia 50
- **Foma** — דפי נתונים של Fomapan 100/400
- **Howard Bond** — "Black and White Reciprocity Departure Revisited",
  PHOTO Techniques, Jul/Aug 2003. מדידה עצמאית בדנסיטומטר.
- **Andrew Roos** — בדיקות עצמאיות ל-Delta 100, מאששות את Bond בקצה הארוך.

כשהמקורות חלוקים הכלי מציג טווח ולא מספר בודד. בטווח שבו למדידה העצמאית
יש אישוש בלתי תלוי היא מובילה; מחוצה לו מוצג הממוצע בין המקורות.

## עדכון הכלי
ה-service worker שומר במטמון. **כל שינוי ב-index.html מחייב העלאת `CACHE`
ב-sw.js** (`hasifon-v1` → `hasifon-v2`), אחרת מכשירים ימשיכו להגיש את
הגרסה הישנה ללא הגבלת זמן.
